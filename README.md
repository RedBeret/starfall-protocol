# Starfall Protocol

A first-person science-fiction survival game built for the browser. Explore a failing orbital station, restore its systems, and escape before the station is lost.

The project is currently in its technical-prototype stage. The first milestone proves the rendering, movement, collision, combat-state, and GitHub Pages pipeline that the full game will use.

## Development

```sh
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

## Planned controls

- `W` / `A` / `S` / `D` or arrow keys — move
- Mouse — look
- Left click or `Space` — fire
- `Shift` — sprint
- `F` — fullscreen
- `Esc` — release the mouse and pause
